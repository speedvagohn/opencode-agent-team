# Готовые сообщения для установки

Скопируй **одно** сообщение в чат opencode на машине друга — агент сделает всё сам.

## Вариант 1 — «поставь всё» (основной)

```
Установи систему агентов по инструкции: https://raw.githubusercontent.com/speedvagohn/opencode-agent-team/v1.4/INSTALL-AGENTS.md — прочитай её и выполни полностью. Ставь всё сразу, лишних вопросов не задавай. В конце скажи, что нужно сделать с меня.
```

## Вариант 2 — «с выбором состава»

```
Прочитай https://raw.githubusercontent.com/speedvagohn/opencode-agent-team/v1.4/INSTALL-AGENTS.md и выполни установку. Перед стартом спроси меня, что ставить.
```

## Вариант 3 — если ссылка не открывается (нет webfetch, прокси, нет интернета)

Скачай/открой файл `INSTALL-AGENTS.md` (кнопка Raw на GitHub или ссылка выше), **вставь его содержимое в чат** и добавь:

```
Выполни эту инструкцию полностью. Ставь всё сразу, лишних вопросов не задавай.
```

## Что произойдёт дальше

1. Агент задаст **один вопрос**: «всё сразу / только конвейер агентов / только MCP и админ / свой набор».
2. Проверит предусловия и при необходимости доустановит git/Node (winget) — либо обойдётся без git.
3. Скачает zip **того же тега `v1.4`** и запустит установщик (Node.js, bun, uv ставятся сами, если нужны).
4. Проверит результат и сообщит, что установлено / что пропущено и почему.
5. Попросит **перезапустить opencode** (правки конфига и агентов читаются только при старте).

## Что нужно от человека

- **Несколько подтверждений** на запись в `%USERPROFILE%\.config\opencode` и `%USERPROFILE%\tools` — это пути вне рабочей папки opencode, поэтому он спрашивает. Разрешать безопасно: установщик только копирует файлы и дописывает секции `mcp` в конфиг, предыдущая версия остаётся рядом как `opencode.json.bak.*`.
- **Перезапуск opencode** в конце.
- Ответ на один вопрос о составе установки (если не выбран вариант «всё сразу»).

## После установки

```
@orchestrator новый проект, папка C:\путь\к\проекту, хочу <задачу>
```

Мелкие правки — агентом `build`, настройка MCP — агентом `mcp-admin`.
