# opencode-agent-team

Готовая команда агентов для [OpenCode](https://opencode.ai): конвейер разработки проектов
(посредник → архитектор → исполнитель → критик → ревьюер), MCP-серверы (веб-поиск,
браузер, память, документация библиотек, структурированное рассуждение) и агент-администратор
для настройки всего этого.

Никакой привязки к проекту, стеку или машине: система универсальна, все пути вычисляются
при установке.

## Установка: скопируй это сообщение в чат opencode

```
Установи систему агентов по инструкции: https://raw.githubusercontent.com/speedvagohn/opencode-agent-team/v1.4/INSTALL-AGENTS.md — прочитай её и выполни полностью. Ставь всё сразу, лишних вопросов не задавай. В конце скажи, что нужно сделать с меня.
```

Варианты для выборочной установки и случаев без webfetch — в [`INSTALL-MESSAGE.md`](./INSTALL-MESSAGE.md).

Требования: Windows + Node.js (остальное ставится автоматически) либо ручной путь в инструкции
для macOS/Linux.

## Три профиля

| Профиль | Состав | Когда нужен |
|---|---|---|
| `agent-team` | 6 агентов + 7 MCP + 2 скилла + глобальные правила | полная система с нуля (по умолчанию) |
| `orchestrator` | 5 агентов конвейера | MCP уже стоят или не нужны |
| `mcp-admin` | 7 MCP + агент mcp-admin + 2 скилла | нужны инструменты и админ, без конвейера разработки |

Готовые zip-архивы — в [`dist/`](./dist).

### Выборочная установка (компоненты)
Установщик принимает `-Skip` со списком через запятую — можно поставить не всё сразу, а только нужное:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1                                  # всё
powershell -ExecutionPolicy Bypass -File install.ps1 -Skip mcp                         # только агенты, без MCP
powershell -ExecutionPolicy Bypass -File install.ps1 -Skip "memory,office"             # всё, кроме памяти и Office
powershell -ExecutionPolicy Bypass -File install.ps1 -Skip "agents,skills,memory"      # только MCP-поиск и браузер
```

Ключи: `mcp` (сразу все MCP), `agents`, `admin`, `skills`, `instructions`, `memory`, `ddg`,
`playwright`, `context7`, `sequentialthinking`, `office`, `unity`. Зависимости проверяются
лениво: Node.js нужен только для npx-MCP, bun/uv ставятся сами и только когда нужны,
поэтому установка «только агенты» работает на машине без Node.js.

## Роли агентов

| Агент | Назначение |
|---|---|
| **orchestrator** (primary) | Единственный интерактивный узел: принимает задачу, ведёт конвейер и гейты, делает чекпоинты в файлы + память, ведёт обязательный git проекта с таймстемпами, пишет историю проекта автоматически |
| **architect** | Уточняет требования до достаточности, пишет SPEC и декомпозицию задач с DoD и командами проверки |
| **executor** | Решает одну задачу в границах брифа, прогоняет верификацию, отчитывается отдельным файлом |
| **critic** | Ревьюит план до кода и результаты после; перепрогоняет верификацию, ищет блокеры, ведёт claims-only анти-якорение |
| **reviewer** | Финальное интеграционное ревью (сквозной сценарий, стыки, регресс) + сборка истории проекта |
| **mcp-admin** (primary) | Настройка и диагностика MCP-серверов, обслуживание ОС |

## Что делает система

- **Требования до 100% достаточности**: архитектор не декомпозирует, пока не определены
  требования, способ решения и стратегия проверки; непроверенные допущения помечаются `[ASSUMPTION]`.
- **Гейты у человека**: только старт плана, эскалации и финальное принятие.
- **История проекта всегда и автоматически**: одна строка на событие в `STATE/HISTORY.md`
  и индекс; читается по запросу и по «правилу двух попыток» перед третьей попыткой починки.
- **Обязательный git проекта**: авто-`.gitignore`, baseline-коммит, коммиты на закрытые
  задачи и фазы; push — только по явной просьбе пользователя.
- **Capability audit на старте**: недостающие инструменты фиксируются явно, есть режим
  автоустановки через mcp-admin на гейтах.
- **Модели по ролям** задаются в frontmatter агентов; при отсутствии нужной модели строки
  `model:` снимаются, и агенты наследуют модель сессии.

## Структура

```
agent/            определения агентов (markdown + frontmatter)
skills/           memory-mcp, deep-reasoning
instructions.md   глобальные правила работы с инструментами
packages/         три профиля: INSTRUCTION.md + install.ps1 (+ сервер памяти)
dist/             готовые zip для оффлайн-установки
INSTALL-AGENTS.md инструкция для агента-установщика
```

## Безопасность

Установщик идемпотентен, делает бэкап `opencode.json.bak.*`, не трогает существующие
MCP-серверы и чужие агентов. Установка описанными здесь средствами не вызывает
`git push`, не использует `--auto` и не изменяет remote.

## Версионирование

Установка по тегу: `--branch v1.0`. Обновление — снять старые файлы агентов/скиллов
и прогнать установщик новой версии (или `git fetch --tags && git checkout <тег>` и заново
запустить `install.ps1`).
